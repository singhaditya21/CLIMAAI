## 2024-05-18 - Improve Keyboard Focus and Screen Reader Flow
**Learning:** Decorative icons (like emojis) placed next to descriptive text labels inside interactive elements (e.g., `.nav-btn`) can cause redundant or confusing screen reader announcements. Furthermore, applying global `*:focus-visible` to satisfy keyboard accessibility can cause unexpected visual regressions on scrollable containers natively focused by modern browsers.
**Action:** Use `aria-hidden="true"` specifically on the spans wrapping decorative emojis when adjacent visible text already describes the action. Additionally, rather than adding new custom CSS classes or global wildcards for focus states, safely provide keyboard focus indicators by grouping the `:focus-visible` pseudo-class with existing interactive element `:hover` styles (e.g., `.nav-btn:hover, .nav-btn:focus-visible`) to maintain design consistency.

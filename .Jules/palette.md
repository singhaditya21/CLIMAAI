## 2024-05-24 - Global Focus Visible Styling
**Learning:** Modern browsers natively curve focus outlines to match the element's `border-radius`. Therefore, setting `border-radius: inherit` for focus outlines is an anti-pattern that can incorrectly force inheritance from a parent container. Additionally, when applying a global `:focus-visible` to interactive elements, elements that manage their own focused state (like inputs with custom `box-shadow` styles) must be explicitly excluded via `:not()` to avoid duplicate or conflicting focus rings.
**Action:** When applying global `:focus-visible` accessibility styles in the `web-demo` app, explicitly exclude elements that already handle their own focus states (e.g., `.form-group input`, `.setting-select`) to prevent duplicate focus rings. Reuse existing CSS color variables (e.g., `var(--primary-light)`) for consistency. Avoid using `border-radius: inherit` for focus outlines.

## 2025-04-07 - Add Keyboard Focus Indicators
**Learning:** Modern browsers may not natively add focus rings when an element has `border-radius` applied if `outline` isn't specified, and relying purely on global `*:focus-visible` breaks complex layout containers. Furthermore, grouping `:focus-visible` pseudo-classes with existing `:hover` CSS blocks allows us to safely and accessibly reuse interactive styling patterns (like background shifts or box shadows) without defining custom CSS classes.
**Action:** When improving keyboard accessibility on interactive elements in constrained environments (like the "no custom CSS" boundary), group `:focus-visible` with existing `:hover` rules and explicitly set the `outline` property reusing existing color tokens (e.g., `var(--primary-light)`).

## 2024-05-24 - Global Keyboard Focus Indicators
**Learning:** Using a global `*:focus-visible` selector instead of `:focus` is crucial for adding visible focus rings (outlines) exclusively for keyboard navigation without creating unwanted outlines on mouse clicks (which happens with just `:focus`). Custom elements that handle their own states, such as `.form-group input` and `.setting-select`, should be explicitly excluded from global focus styles to avoid duplicate focus indicators. Modern browsers also correctly natively match the curve of standard CSS `outline` with the element's border-radius.
**Action:** When adding accessible focus states, prefer `*:focus-visible`, implement exclusions for custom styled elements (`not(...)`), and avoid manually setting `border-radius: inherit` on outlines.

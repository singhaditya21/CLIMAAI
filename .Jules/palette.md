## 2026-03-14 - Global `:focus-visible` Accessibility Enhancement
**Learning:** When applying global `:focus-visible` accessibility styles, explicitly exclude elements that already handle their own focus states (e.g., `.form-group input`, `.setting-select`) to prevent duplicate or conflicting focus rings. Additionally, when fixing missing keyboard focus indicators in custom UI components, reuse existing CSS color variables (e.g., `var(--primary-light)`). Avoid using `border-radius: inherit` for focus outlines, as it incorrectly forces inheritance from the parent container; modern browsers natively curve outlines to match the element's border-radius.
**Action:** When adding global `:focus-visible` styles to any project, use the `:not()` pseudo-class to exclude elements that manage their own focus styles. Reuse existing design system colors like `var(--primary-light)` for the focus ring and rely on modern browsers' native outline curving instead of explicitly inheriting border-radius.

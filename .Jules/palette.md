## 2026-03-27 - Native Focus Rings and Inheritance\n**Learning:** The `web-demo` app aggressively strips native focus rings using global `outline: none`. Also, using `border-radius: inherit` for focus outlines incorrectly forces inheritance from the parent container instead of the element itself.\n**Action:** When applying global `:focus-visible` accessibility styles, explicitly exclude elements that already handle their own focus states (e.g., `.form-group input`, `.setting-select`) using `:not()` to prevent duplicate or conflicting focus rings, and avoid using `border-radius: inherit`.

## 2024-03-20 - Reliable Loading States for Vanilla JS Forms
**Learning:** When implementing accessible loading states (using `aria-busy` and `disabled`) on form submission buttons in Vanilla JS, relying purely on element selectors can be brittle if multiple buttons exist or if the DOM structure changes. Furthermore, using a standard `setTimeout` callback makes it difficult to reliably restore the button state using a `finally` block if an error occurs inside the async operation.
**Action:** Use `e.submitter` to precisely target the button that triggered the form submission, wrap its property access in a null-check, and always handle the async state restoration in a `finally` block to ensure the UI recovers regardless of API success or failure. Convert standard `setTimeout` delays in simulated async operations into awaitable Promises (`await new Promise(...)`) to enable the use of `try/finally` blocks around the entire operation.

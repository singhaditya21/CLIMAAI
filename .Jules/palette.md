## 2024-05-24 - Focus-Visible Accessibility Improvements
**Learning:** When applying global `:focus-visible` accessibility styles, modern browsers natively curve outlines to match the element's border-radius. Avoid using `border-radius: inherit` for focus outlines, as it incorrectly forces inheritance from the parent container. Reusing existing CSS color variables (e.g., `var(--primary-light)`) ensures design consistency. Explicitly exclude elements that already handle their own focus states (e.g., `.form-group input`) to prevent duplicate or conflicting focus rings.
**Action:** Always add a global `:focus-visible` rule using existing color variables and an appropriate `outline-offset` (e.g., `2px`). Exclude elements with custom focus states. When testing with Playwright, use `page.keyboard.press('Tab')` to simulate keyboard navigation, as programmatic or mouse focus might not trigger the `:focus-visible` styles.

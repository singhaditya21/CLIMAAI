## 2026-03-20 - Global Keyboard Focus Indicators
**Learning:** Modern browsers natively curve focus outlines to match the element's border-radius. Avoid using `border-radius: inherit` for focus outlines as it incorrectly forces inheritance from the parent container. Additionally, when applying global `:focus-visible` accessibility styles, explicitly exclude elements that already handle their own focus states (e.g., `.form-group input`, `.setting-select`) to prevent duplicate or conflicting focus rings. When testing `:focus-visible` styles with Playwright, use `page.keyboard.press('Tab')` to simulate keyboard navigation rather than `element.focus()`, because modern browsers may not render the focus outline when an element receives programmatic or mouse focus.
**Action:** Implement global `:focus-visible` outline styles relying on native browser border-radius curving. Use `:not()` selectors to skip elements with custom focus states, and use `page.keyboard.press('Tab')` in e2e tests for accurate focus-visible simulation.

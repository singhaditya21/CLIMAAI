## 2024-03-26 - Add global focus indicators for accessibility
**Learning:** Modern browsers (Chromium, Firefox, Safari) natively curve the default `outline` or custom outlines applied with `:focus-visible` to match the exact `border-radius` of the element. Using `border-radius: inherit` with custom focus rings can incorrectly force inheritance from a parent container, causing visually awkward styling. Furthermore, applying universal focus styles globally must strictly exclude elements that manage their own complex focus states (e.g., `.form-group input`, `.setting-select`) via `:not()` to prevent duplicate, conflicting focus rings.
**Action:** When adding global focus styles (`:focus-visible`) across the application, apply standard `outline` rules on elements and explicitly ignore inputs/selects that have customized focus `box-shadow` styles. Avoid overriding the focus ring's border-radius; let the browser conform it natively.

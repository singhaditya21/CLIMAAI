## 2024-04-10 - Refined Keyboard Focus and Screen Reader Accessibility
**Learning:** Adding the `:focus-visible` pseudo-class to existing interactive elements' `:hover` blocks successfully introduces native keyboard navigation focus outlines while adhering to the "no custom CSS" boundary. Additionally, applying `aria-hidden="true"` to structural/decorative text-icons (like emojis inside buttons) effectively mitigates redundant or distracting screen reader announcements, especially when an adjacent text label is already present.
**Action:** When implementing keyboard accessibility within strict design system constraints, group `:focus-visible` alongside `:hover` styles to reuse visual patterns safely. Furthermore, consistently apply `aria-hidden="true"` to isolated emoji/icon elements that have corresponding textual labels to streamline the screen reader experience.

## 2024-03-25 - Global outline reset pattern
**Learning:** The web-demo app aggressively strips native focus rings using global `outline: none` on interactive elements without providing accessible alternatives. When fixing missing keyboard focus indicators (`:focus-visible`), using `border-radius: inherit` for focus outlines fails because it incorrectly forces inheritance from the parent container rather than the element itself. Modern browsers natively curve standard outlines to match the element's border-radius.
**Action:** When applying global `:focus-visible` accessibility styles, rely on standard browser outline curvature instead of inherited border radius, and explicitly exclude elements that already handle their own focus states (e.g., `.form-group input`, `.setting-select`) to prevent duplicate or conflicting focus rings.

## 2024-05-18 - Prevent Redundant Emoji Announcements and Fix Focus States
**Learning:** Screen readers announce emojis embedded in UI elements, which can create redundant and confusing experiences when descriptive text labels are already present adjacent to them (e.g., in `.nav-btn`). Also, ensuring keyboard accessibility requires explicit `:focus-visible` pseudo-classes on interactive components to match existing `:hover` states without adding global wildcard rules that affect scrollable layout containers.
**Action:** Apply `aria-hidden="true"` to `<span>` elements wrapping decorative emojis when they are grouped with visible text labels. Group `:focus-visible` rules with existing `:hover` styles for interactive classes to guarantee keyboard focus indicators without violating design constraints.

## 2024-04-03 - Global Focus Ring Management
**Learning:** Adding a global `*:focus-visible` ring must be carefully scoped using `:not()` selectors to avoid duplicating or conflicting with elements (like `.form-group input` and `.setting-select`) that already implement custom focus states in their design system. Using CSS variables for color (e.g., `var(--primary-light)`) ensures theme compatibility. Playwright scripts simulating `Tab` presses are required to reliably verify `:focus-visible`, as programmatic `focus()` often doesn't trigger the visual ring in modern browsers.
**Action:** When establishing global accessibility baselines like focus rings, audit the codebase for components that manage their own focus and explicitly exclude them. Use `page.keyboard.press('Tab')` for E2E focus verification.

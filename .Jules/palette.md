## 2024-05-18 - Improve Keyboard Accessibility via global `:focus-visible` styles
**Learning:** Adding a global `*:focus { outline: none; }` and handling `*:focus-visible` with a 2px solid outline drastically improves keyboard navigation for non-mouse users without compromising visual design on click. Using `border-radius: inherit` causes incorrect outline behavior on modern browsers since they automatically curve outlines according to the element's `border-radius`. We also need to be careful to `not()` select elements that handle their own focus states, like `.form-group input` and `.setting-select`, to prevent redundant/conflicting focus rings.
**Action:** Use global `*:focus-visible` in CSS, skipping elements that require custom focus states. Avoid `border-radius: inherit` for focus outlines.

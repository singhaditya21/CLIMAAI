## 2024-03-16 - Global Keyboard Focus Styles
**Learning:** When applying global `:focus-visible` accessibility styles (like `outline: 2px solid var(--primary-light)`), modern browsers automatically curve the outline to match the element's `border-radius`. Therefore, using `border-radius: inherit` is unnecessary and often incorrect as it forces inheritance from the parent container instead of the element itself. Additionally, components that already manage their own complex focus states (e.g., `.form-group input`, `.setting-select`) must be explicitly excluded to prevent duplicate or conflicting focus rings.
**Action:** Always test `:focus-visible` using keyboard navigation (`Tab` key), and ensure global outlines exclude custom form elements. Rely on the browser's native rounding for outlines instead of CSS hacks.

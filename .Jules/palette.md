## 2026-05-27 - [Vanilla JS Async Button Loading States]
**Learning:** When managing loading states for buttons during asynchronous operations in vanilla JavaScript, especially simulated ones, it is critical to convert callback-based delays (like `setTimeout`) into awaitable Promises (`await new Promise(resolve => setTimeout(resolve, delay))`). This ensures the `finally` block waits for the operation to complete, allowing robust cleanup (restoring `innerHTML`, `disabled=false`, `aria-busy`). Furthermore, checking `e.submitter` on forms is key for properly attributing loading states to the correct triggering button.
**Action:** Use `e.submitter` on forms or `e.currentTarget` on button clicks, carefully cache original `innerHTML`, apply `disabled` and `aria-busy`, and guarantee restoration using a `try...finally` structure with fully awaited asynchronous logic.

## 2024-05-18 - Decorative Emojis & Focus Navigation
**Learning:** Screen readers redundantly announce decorative emojis in interactive components (like nav buttons) when descriptive text already exists. Adding `aria-hidden="true"` exclusively to the emoji `<span>` prevents double-announcements while maintaining visual context. Additionally, applying `:focus-visible` styles by grouping them with existing `:hover` CSS classes provides robust, accessible keyboard indicators without introducing new global custom CSS classes that could cause unintended visual regressions.
**Action:** Always add `aria-hidden="true"` to icon `<span>` elements when adjacent text labels are present. Default to sharing `:hover` block rules with `:focus-visible` on interactive UI components in vanilla HTML/CSS stacks.

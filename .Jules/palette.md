## 2026-03-09 - Keyboard Accessibility Focus Rings in Web Demo
**Learning:** Modern browsers natively curve outline rings to match an element's `border-radius`. When applying a global `:focus-visible` rule, it's crucial not to force `border-radius: inherit` for the outline as this breaks the native rendering and causes incorrect styling when navigating via keyboard. Additionally, components like form inputs that handle their own `:focus` states need to be explicitly excluded from the global `:focus-visible` rule to prevent duplicate, conflicting focus rings.
**Action:** When adding global accessibility styles like `:focus-visible`, rely on the browser's native handling for outline curves. Always identify and exclude components that already manage custom focus indicators to maintain a polished UI experience.

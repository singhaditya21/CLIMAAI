## 2024-04-16 - Add :focus-visible states to buttons for keyboard navigation
**Learning:** The web-demo app had interactive elements like buttons and navigation icons that lacked clear visual indicators when focused via keyboard (tab navigation). This is a critical accessibility issue, as users navigating via keyboard need to know which element has focus. However, adding a global `*:focus { outline: none; }` or custom global `:focus-visible` rules is prohibited by the design constraints.
**Action:** Group `:focus-visible` pseudo-class selectors with existing `:hover` CSS blocks for specific interactive components (e.g., `.btn`, `.nav-btn`, `.icon-btn`, `.theme-toggle`) in `style.css`. This safely reuses existing hover styles (backgrounds, transforms, box-shadows) for focus states, ensuring keyboard accessibility without introducing new custom CSS classes or global outlines.

Privacy policy

ClimaAI weather website · Updated 23 September 2026

The ClimaAI website shows live weather without an account, ads, analytics, or tracking scripts. It does not store your searches, coordinates, or forecast history in a ClimaAI account or browser storage.

Weather and place search

When the site loads, your browser requests a forecast for New Delhi, India from Open-Meteo. If you search for a place, the text you enter goes directly from your browser to Open-Meteo's geocoding service. When you choose a place, its coordinates go directly to Open-Meteo's forecast service. Open-Meteo receives your IP address as part of those requests. See Open-Meteo's terms and privacy information.

Optional device location

The website asks for location access only when you select “Use my location.” If you allow it, your browser provides coordinates to this page, which sends them to Open-Meteo for the forecast. You can decline and search by city instead. The website does not save those coordinates between visits.

Hosting and retention

GitHub Pages hosts this static website and necessarily receives ordinary web requests, including your IP address. GitHub's own handling of that data is described in its privacy statement. ClimaAI does not run a website backend or maintain user accounts for this site.

Mobile apps

The Android and iOS applications in this project are not part of this website release. Their account and backend features are not offered on this site.

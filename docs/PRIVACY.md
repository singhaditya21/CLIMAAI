# Privacy Policy

The canonical, user-facing privacy policy is
[privacy.html](https://singhaditya21.github.io/CLIMAAI/privacy.html), served
from this folder by GitHub Pages. That page is what the store listings link to.

The Markdown policy that used to live here was written for a product that was
never shipped — it promised OpenAI data sharing, analytics collection, a
12-month usage-data retention window, and `@climaai.com` contact addresses,
none of which exist. It was replaced rather than edited so the HTML page has
exactly one source of truth.
